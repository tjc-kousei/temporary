# 聚会管理系统 (简体中文)

[返回主页 (日本語)](README.md)

## 主要功能

### 基本信息管理

- **聚会信息**: 输入并管理聚会类型、讲道主题（中日双语）、讲道人和口译员信息。
- **自动保存**: 输入的信息存储在浏览器 Cookie 中。
- **同工名单**: 通过 URL 参数自动获取特定教会的同工名单。

### 圣经投影

- **双语显示**: 可同时投影日语和中文经文。
- **全文检索**: 支持通过关键词在圣经数据中进行搜索。
- **历史记录**: 手动登记经文，方便快速投影。

### 赞美诗显示

- **歌词加载**: 根据编号从歌词 API 读取歌词。已取得的数据会保存在浏览器中，离线或通信失败时可继续使用保存数据。
- **分节控制**: 为每一节生成按钮，支持按需切换投影内容。
- **注音与自适应**: 支持自动注音功能，并根据窗口大小自动调整字体大小。

## 桌面布局与即时投影

- 右上角「画面スタイル」可选择「従来スタイル」或「新スタイル」。默认使用原有卡片布局，选择会保存在当前浏览器中。
- 两种布局都即时反映基本信息、经文章节和赞美诗编号，不需要Enter或确认按钮。清空或输入不存在的经文时，投影正文变为空白。
- 切换布局不会清空输入或关闭投影窗口。新布局保留固定操作栏、投影预览与黑屏功能。
- 画面捕获功能暂时关闭：隐藏操作按钮，并阻止启动、重新选择和切换到捕获模式。
- 操作页面底部以浅色显示「最終更新」。日期来自GitHub Pages提供的HTML `Last-Modified`，按日本时间显示；无法取得时不显示。投影窗口不显示日期。
- 详细操作与测试方法参见[日文README](README.md)。

# 歌词数据规范

当前前端不会直接读取本地 `lyrics/*.txt`，而是使用歌词 API 的响应数据。

### 1. 数据结构

- **API**: `https://tjckousei.com/hymn/api.php?action=get_all_lyrics`
- **键名**: `[编号].txt` (例如: `1.txt`)
- **缓存**: 获取到的数据会保存到浏览器 `localStorage`。

### 2. 编写格式

```text
[1]
第一节歌词
[2]
第二节歌词
```

### 3. 注音功能

在汉字后紧跟 `(注音)` 即可。
示例: `荣耀(róngyào)`。
