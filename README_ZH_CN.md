# 聚会管理系统 (简体中文)

[返回主页 (日本語)](README.md)

## 主要功能

### 基本信息管理

- **聚会信息**: 输入并管理聚会类型、讲道主题（中日双语）、讲道人和口译员信息。
- **自动保存**: 输入的信息存储在浏览器 Cookie 中。
- **同工名单**: 通过 URL 参数自动获取特定教会的同工名单。

### 圣经投影

- **双语显示**: 可同时投影日语和中文经文。
- **全文检索**: 支持通过关键词在圣经数据中进行搜索。
- **历史记录**: 手动登记经文，方便快速投影。

### 赞美诗显示

- **歌词加载**: 根据编号从歌词 API 读取歌词。已取得的数据会保存在浏览器中，离线或通信失败时可继续使用保存数据。
- **分节控制**: 为每一节生成按钮，支持按需切换投影内容。
- **注音与自适应**: 支持自动注音功能，并根据窗口大小自动调整字体大小。

## 桌面投影操作

- 顶部固定栏用于切换投影内容，并显示连接状态和当前模式；右侧提供投影预览。
- 基本信息输入时仅保存草稿，点击「投影に反映」后才更新投影。启动时不会自动打开投影窗口。
- 经文章节直接输入后按Enter确认。前后按钮以当前投影的经文为基准即时切换；输入无效章节或清空输入不会清除正在投影的内容。
- 「黒画面にする」临时遮挡全部输出，「投影を再開」恢复显示。黑屏期间可更改内容，恢复时显示更改后的内容；屏幕共享不会因此停止。
- 「礼拝讃美歌」中的曲目可以在「讃美歌」卡片中直接选择；直接输入编号后按Enter或点击「曲を選択」。
- 「聖句を登録」手动登记经文，登记列表仅在当前页面会话中保存。搜索结果或登记列表可一键投影。
- 搜索对话框支持Tab／Shift+Tab循环操作，关闭或按Escape后焦点返回打开按钮。
- 「投影画面を全画面に」控制投影窗口的全屏状态。若弹出窗口被阻止，请在浏览器允许后重试。

本界面面向桌面使用。运行方法与测试命令请参阅[日文README](README.md#ローカル起動・検証)。

# 歌词数据规范

当前前端不会直接读取本地 `lyrics/*.txt`，而是使用歌词 API 的响应数据。

### 1. 数据结构

- **API**: `https://tjckousei.com/hymn/api.php?action=get_all_lyrics`
- **键名**: `[编号].txt` (例如: `1.txt`)
- **缓存**: 获取到的数据会保存到浏览器 `localStorage`。

### 2. 编写格式

```text
[1]
第一节歌词
[2]
第二节歌词
```

### 3. 注音功能

在汉字后紧跟 `(注音)` 即可。
示例: `荣耀(róngyào)`。
