# 聚會管理系統 (繁體中文)

[返回主頁 (日本語)](README.md)

## 主要功能

### 基本資訊管理

- **聚會資訊**: 輸入並管理聚會類型、講道主題（中日雙語）、講道者及口譯員資訊。
- **自動保存**: 資訊會自動儲存於瀏覽器的 Cookie 中。
- **人員名單**: 透過 URL 參數動態載入對應的聖工人員名單。

### 聖經投影

- **雙語顯示**: 支持中日文經文同時投影。
- **全文檢索**: 支持關鍵字搜尋功能。
- **記憶功能**: 可從歷史紀錄中快速選擇並顯示經文。

### 讚美詩顯示

- **歌詞載入**: 輸入編號即可從 `lyrics/*.txt` 載入歌詞。
- **章節控制**: 每一節都會產生獨立按鈕，方便切換顯示。
- **自動注音與縮放**: 支持漢字自動注音，並隨視窗大小自動調整字體。

# 歌詞文件規範 (lyrics/\*.txt)

### 1. 檔案

- **路徑**: `lyrics/` 資料夾內
- **檔案名稱**: `[編號].txt` (例如: `100.txt`)

### 2. 編寫格式

```text
[1]
第一節歌詞
[2]
第二節歌詞
```

### 3. 注音標記

在漢字後方使用 `(注音)` 格式。
範例: `榮耀(róngyào)`。
