# 聚會管理系統 (繁體中文)

[返回主頁 (日本語)](README.md)

## 主要功能

### 基本資訊管理

- **聚會資訊**: 輸入並管理聚會類型、講道主題（中日雙語）、講道者及口譯員資訊。
- **自動保存**: 資訊會自動儲存於瀏覽器的 Cookie 中。
- **人員名單**: 透過 URL 參數動態載入對應的聖工人員名單。

### 聖經投影

- **雙語顯示**: 支持中日文經文同時投影。
- **全文檢索**: 支持關鍵字搜尋功能。
- **記憶功能**: 可從歷史紀錄中快速選擇並顯示經文。

### 讚美詩顯示

- **歌詞載入**: 輸入編號後會從歌詞 API 載入歌詞。已取得的資料會儲存在瀏覽器中，離線或連線失敗時可繼續使用保存資料。
- **章節控制**: 每一節都會產生獨立按鈕，方便切換顯示。
- **自動注音與縮放**: 支持漢字自動注音，並隨視窗大小自動調整字體。

## 桌面配置與即時投影

- 右上角「画面スタイル」可選擇「従来スタイル」或「新スタイル」。預設使用原有卡片配置，選擇會儲存在目前瀏覽器中。
- 兩種配置都即時反映基本資訊、經文章節與讚美詩編號，不需要Enter或確認按鈕。清空或輸入不存在的經文時，投影正文變為空白。
- 切換配置不會清空輸入或關閉投影視窗。新配置保留固定操作列、投影預覽與黑畫面功能。
- 畫面擷取功能暫時關閉：隱藏操作按鈕，並阻止啟動、重新選擇和切換到擷取模式。
- 操作頁面底部以淺色顯示「最終更新」。日期來自GitHub Pages提供的HTML `Last-Modified`，按日本時間顯示；無法取得時不顯示。投影視窗不顯示日期。
- 詳細操作與測試方法參見[日文README](README.md)。

# 歌詞資料規範

目前前端不會直接讀取本機 `lyrics/*.txt`，而是使用歌詞 API 的回應資料。

### 1. 資料結構

- **API**: `https://tjckousei.com/hymn/api.php?action=get_all_lyrics`
- **鍵名**: `[編號].txt` (例如: `100.txt`)
- **快取**: 取得的資料會保存到瀏覽器 `localStorage`。

### 2. 編寫格式

```text
[1]
第一節歌詞
[2]
第二節歌詞
```

### 3. 注音標記

在漢字後方使用 `(注音)` 格式。
範例: `榮耀(róngyào)`。
