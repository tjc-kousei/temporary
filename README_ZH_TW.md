# 聚會管理系統 (繁體中文)

[返回主頁 (日本語)](README.md)

## 主要功能

### 基本資訊管理

- **聚會資訊**: 輸入並管理聚會類型、講道主題（中日雙語）、講道者及口譯員資訊。
- **自動保存**: 資訊會自動儲存於瀏覽器的 Cookie 中。
- **人員名單**: 透過 URL 參數動態載入對應的聖工人員名單。

### 聖經投影

- **雙語顯示**: 支持中日文經文同時投影。
- **全文檢索**: 支持關鍵字搜尋功能。
- **記憶功能**: 可從歷史紀錄中快速選擇並顯示經文。

### 讚美詩顯示

- **歌詞載入**: 輸入編號後會從歌詞 API 載入歌詞。已取得的資料會儲存在瀏覽器中，離線或連線失敗時可繼續使用保存資料。
- **章節控制**: 每一節都會產生獨立按鈕，方便切換顯示。
- **自動注音與縮放**: 支持漢字自動注音，並隨視窗大小自動調整字體。

## 桌面投影操作

- 頂部固定列用於切換投影內容，並顯示連線狀態與目前模式；右側提供投影預覽。
- 基本資訊輸入時僅儲存草稿，按下「投影に反映」後才更新投影。啟動時不會自動開啟投影視窗。
- 經文章節直接輸入後按Enter確認。前後按鈕以目前投影的經文為基準即時切換；輸入無效章節或清空輸入不會清除正在投影的內容。
- 「黒画面にする」暫時遮蔽全部輸出，「投影を再開」恢復顯示。黑畫面期間可更改內容，恢復時顯示更改後的內容；螢幕分享不會因此停止。
- 「礼拝讃美歌」中的曲目可在「讃美歌」卡片中直接選擇；直接輸入編號後按Enter或點選「曲を選択」。
- 「聖句を登録」手動登記經文，登記清單僅在目前頁面工作階段中保留。搜尋結果或登記清單可一鍵投影。
- 搜尋對話框支援Tab／Shift+Tab循環操作，關閉或按Escape後焦點返回開啟按鈕。
- 「投影画面を全画面に」控制投影視窗的全螢幕狀態。若彈出視窗遭阻擋，請在瀏覽器允許後重試。

本介面面向桌面使用。執行方法與測試指令請參閱[日文README](README.md#ローカル起動・検証)。

# 歌詞資料規範

目前前端不會直接讀取本機 `lyrics/*.txt`，而是使用歌詞 API 的回應資料。

### 1. 資料結構

- **API**: `https://tjckousei.com/hymn/api.php?action=get_all_lyrics`
- **鍵名**: `[編號].txt` (例如: `100.txt`)
- **快取**: 取得的資料會保存到瀏覽器 `localStorage`。

### 2. 編寫格式

```text
[1]
第一節歌詞
[2]
第二節歌詞
```

### 3. 注音標記

在漢字後方使用 `(注音)` 格式。
範例: `榮耀(róngyào)`。
