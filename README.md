# 集会管理システム (Assembly Management System)

このシステムは、教会の集会において聖句、讃美歌、および集会情報をプロジェクター等で投影・管理するための Web アプリケーションです。

## 他言語版 / Other Languages

- [English / Chinese (Simplified)](README_ZH_CN.md)
- [Chinese (Traditional)](README_ZH_TW.md)

## 主な機能

### 基本情報管理

- **集会情報**: 礼拝の種類、説教テーマ（日中両言語）、説教者、通訳者の情報を管理します。
- **下書きの自動保存**: 入力データはブラウザの Cookie に保存され、再読み込み後も保持されます。入力途中の内容は投影されず、「投影に反映」で確定します。反映済みの基本情報は `localStorage` に別途保存されます。
- **動的リスト**: URL パラメータ（`?church=教会名`）により、外部から奉仕者名簿を自動取得します。

### 聖書操作

- **二ヶ国語投影**: 日本語と中国語の聖句を同時に表示可能です。
- **全文検索**: 読み込まれた聖書データからキーワードで聖句を検索できます。
- **聖句の登録**: 「聖句を登録」で箇所を登録し、プルダウンから即座に投影できます。登録一覧はページを開いている間のみ保持されます。

- **入力の確定**: 書巻・章・節を指定してEnter、または「聖句を投影（Enter）」で反映します。前後移動は投影中の節を基準に即時反映し、章の範囲外や存在しない節では現在の投影を保持します。

### 讃美歌表示

- **歌詞取得**: 番号入力により歌詞 API から歌詞データを読み込みます。取得済みデータはブラウザに保存され、通信できない場合は保存済みデータを利用します。
- **礼拝讃美歌から選択**: 基本情報に入力した1曲目・2曲目を「讃美歌」カードから直接選べます。番号を直接入力する場合はEnterまたは「曲を選択」で確定します。
- **節単位の制御**: 節（番）ごとにボタンが生成され、表示箇所を自由に切り替えられます。
- **自動ルビ・サイズ調整**: 漢字への自動ルビ振りと、画面サイズに合わせたフォントサイズ調整を行います。

## デスクトップでの操作手順

1. ブラウザで管理画面を開き、基本情報を入力します。「未反映の変更があります」の間は投影先へ送信されません。翻訳候補や奉仕者候補からの入力も同様です。
2. 「投影に反映」を押すと基本情報を確定します。投影画面が未接続の場合は別ウィンドウで開きます。起動時に自動で投影ウィンドウを開くことはありません。
3. 上部の固定バーで基本情報・讃美歌・聖書・画面キャプチャを切り替えます。スクロール中も操作でき、現在のモードと接続状態を表示します。表示モードの切り替えだけでは下書きは確定されません。
4. 右側の「現在投影中」で投影画面を縮小表示します。基本情報・聖書・讃美歌は投影先の表示内容とサイズを反映し、キャプチャ中は共有映像を表示します。プレビュー内から操作することはできません。
5. 「黒画面にする」で出力全体を一時的に隠し、「投影を再開」で戻します。黒画面中に内容やモードを変更しても黒画面を維持し、再開時にその内容を表示します。キャプチャの共有自体は停止しません。
6. 「投影画面を全画面に」で投影先を全画面表示し、「投影画面の設定」で文字サイズ・ロゴ・色などを調整します。ポップアップがブロックされた場合は、ブラウザで許可してから表示ボタンを押してください。

### 聖書・検索の操作

- 直接入力はEnterで確定します。入力欄のクリアや不正な箇所の指定では、現在の投影を消しません。
- 前後ボタンは投影中の聖句から同じ章の前後の節へ移動します。未確定の入力は移動の基準にしません。
- 検索結果の「この聖句を投影」と登録済み聖句の選択は、1回の操作で投影します。
- 検索ダイアログ内ではTab／Shift+Tabで操作が循環します。閉じるボタンまたはEscapeで閉じると、開いたボタンへフォーカスが戻ります。

PCでの操作を対象としています。プレビューは投影画面と同じ縦横比で縮小されますが、実際のプロジェクターの色や明るさは現地で確認してください。

## ローカル起動・検証

静的ファイルをHTTPサーバーで配信します（Node.jsのビルド処理は不要です）。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

`http://127.0.0.1:8765` をブラウザで開きます。画面キャプチャにはHTTPSまたはlocalhost環境と、ブラウザでの共有許可が必要です。

入力確定・投影保持・黒画面の回帰テストはNode.jsで実行できます。

```sh
node --test tests/projection-console.test.cjs
```

# 歌詞データ仕様

現在のフロントエンドはローカルの `lyrics/*.txt` を直接読み込まず、歌詞 API のレスポンスを利用します。

### 1. 取得元

- **API**: `https://tjckousei.com/hymn/api.php?action=get_all_lyrics`
- **レスポンス**: `{ success: true, data: { "1.txt": "...", "124甲.txt": "..." } }` の形式を想定します。
- **キャッシュ**: 取得した `data` はブラウザの `localStorage` に保存されます。

### 2. 書式

各曲の本文は従来と同じく、節ラベルを角括弧で囲みます。

```text
[1]
歌詞の本文
[2]
歌詞の本文
```

### 3. ルビ指定

漢字の後に `(読み)` を記述します。
例: `栄光(えいこう)` → 「栄光」の上に「えいこう」を表示。
