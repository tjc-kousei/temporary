# 集会管理システム (Assembly Management System)

このシステムは、教会の集会において聖句、讃美歌、および集会情報をプロジェクター等で投影・管理するための Web アプリケーションです。

## 他言語版 / Other Languages

- [English / Chinese (Simplified)](README_ZH_CN.md)
- [Chinese (Traditional)](README_ZH_TW.md)

## 主な機能

### 基本情報管理

- **集会情報**: 礼拝の種類、説教テーマ（日中両言語）、説教者、通訳者の情報を管理します。
- **即時反映と自動保存**: 基本情報は入力・候補選択・翻訳適用と同時に、開いている投影画面へ反映します。確認ボタンは不要です。入力データはCookieに保存され、再読み込み後も保持されます。
- **動的リスト**: URL パラメータ（`?church=教会名`）により、外部から奉仕者名簿を自動取得します。

### 聖書操作

- **二ヶ国語投影**: 日本語と中国語の聖句を同時に表示可能です。
- **全文検索**: 読み込まれた聖書データからキーワードで聖句を検索できます。
- **聖句の登録**: 「聖句を登録」で箇所を登録し、プルダウンから即座に投影できます。登録一覧はページを開いている間のみ保持されます。

- **即時反映**: 書巻・章・節の入力をそのまま表示へ反映します。Enterや確定操作は不要です。入力をクリアした場合や存在しない箇所を入力した場合、聖句本文は空になります。

### 讃美歌表示

- **歌詞取得**: 番号入力により歌詞 API から歌詞データを読み込みます。取得済みデータはブラウザに保存され、通信できない場合は保存済みデータを利用します。
- **礼拝讃美歌から選択**: 新スタイルでは、基本情報に入力した1曲目・2曲目を「讃美歌」カードから直接選べます。番号の直接入力も即時反映します。
- **節単位の制御**: 節（番）ごとにボタンが生成され、表示箇所を自由に切り替えられます。
- **自動ルビ・サイズ調整**: 漢字への自動ルビ振りと、画面サイズに合わせたフォントサイズ調整を行います。

## 画面スタイルと操作

画面右上の「画面スタイル」で切り替えます。初回は**従来スタイル**で、選択はブラウザの `localStorage`（`meetingUiStyle`）に保存されます。保存できない環境でも、そのページ内での切り替えは利用できます。

| スタイル | 配置・操作 |
| --- | --- |
| 従来スタイル（初期値） | 基本情報・讃美歌・聖書のカードを横に並べ、表示制御カードを下に配置します。 |
| 新スタイル | 上部の固定操作バー、右側の投影プレビュー、接続状態、黒画面による一時停止を利用できます。 |

スタイルを切り替えても、入力内容・選択中の聖句・投影ウィンドウは維持されます。どちらのスタイルも**即時反映**です。以前の確定ボタンと未反映表示は廃止しました。

1. 基本情報を入力し、「基本情報 表示」で投影ウィンドウを開きます。開いた後の編集はそのまま反映します。起動時には投影ウィンドウを自動で開きません。
2. 聖書は書巻・章・節を選び、「聖書 表示」で表示します。入力時に聖句を更新するため、例えば「16」と入力する途中では「1」の節も表示されます。前後ボタンも入力欄の箇所を基準に移動します。
3. 讃美歌は番号を入力すると読み込み・表示します。投影先が未接続の場合は「讃美歌 表示」で開きます。歌詞の節ボタンで表示箇所を切り替えます。
4. 「全画面表示」（新スタイルでは「投影画面を全画面に」）で投影先を全画面表示します。ポップアップがブロックされた場合はブラウザで許可してから表示ボタンを押してください。

新スタイルのプレビューは投影先と同じ比率で縮小表示します。「黒画面にする」で出力を隠し、「投影を再開」で戻せます。黒画面中も編集は反映されます。黒画面のまま従来スタイルに戻した場合も、表示制御カードに「投影を再開」が残ります。

### 2画面で投影する

「投影画面の設定」→「投影画面の数」で「2画面で投影」をONにします。初期値はOFFで、選択はブラウザに保存されます。ページの再読み込みだけでは投影画面を開きません。表示ボタンを押して接続してください。

- **ON**：1画面目は日本語の聖書、2画面目は中国語の聖書を画面幅いっぱいに表示します。基本情報と讃美歌（タイトル・選択中の節）は両画面に同じ内容を表示し、編集・画面切り替え・黒画面も同期します。
- **OFF**：中国語用の投影ウィンドウを閉じ、1画面目を従来の日本語・中国語の並列表示に戻します。選択中の聖句や讃美歌は維持します。

各ウィンドウを使用するモニターへ移動してください。各投影画面をダブルクリックすると、その画面の全画面表示を切り替えられます。操作画面の全画面ボタンは1画面目が対象です。新スタイルのプレビューは1画面目（日本語）を表示します。

2画面目がブロックされた場合や片方を閉じた場合は、ポップアップを許可して表示ボタンをもう一度押すと不足する画面を再接続します。設定内の接続数で確認できます。

### 聖書検索

- 「記憶」（新スタイルでは「聖句を登録」）で手動登録し、履歴から即座に投影できます。登録一覧はページを開いている間のみ保持します。
- 検索結果の「この聖句を投影」は1回の操作で投影します。
- 検索ダイアログではTab／Shift+Tabが内部を循環し、閉じるボタンやEscapeで閉じると元のボタンにフォーカスが戻ります。

### 画面キャプチャは一時OFF

両スタイルでキャプチャ操作を非表示にし、開始・対象変更・キャプチャ表示への切り替えも無効化しています。ブラウザの共有許可画面は開きません。実装自体は残してあり、`script.js` の `SCREEN_CAPTURE_ENABLED` は `false` です。再開する際はフラグと非表示のUIを併せて見直してください。

### 最終更新日

操作画面下部に、公開ページの更新日を薄い文字で表示します。GitHub PagesがHTMLのHTTP応答に付ける `Last-Modified` を取得し、日本時間の日付として表示します。Gitの最終コミット日時ではなく**配信されているページの更新日時**です。APIキーや公開ワークフローの追加は不要です。

日時を取得できない場合（オフライン、ヘッダーなしなど）は表示しません。閲覧日を更新日として代用することはありません。ローカルHTTPサーバーではHTMLファイルの更新日時が表示されます。投影画面には更新日を表示しません。

## ローカル起動・検証

静的ファイルをHTTPサーバーで配信します（Node.jsのビルド処理は不要です）。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

`http://127.0.0.1:8765` をブラウザで開きます。

即時反映・スタイル切り替え・キャプチャOFF・更新日の回帰テストはNode.jsで実行できます。

```sh
node --test tests/projection-console.test.cjs
```

# 歌詞データ仕様

現在のフロントエンドはローカルの `lyrics/*.txt` を直接読み込まず、歌詞 API のレスポンスを利用します。

### 1. 取得元

- **API**: `https://tjckousei.com/hymn/api.php?action=get_all_lyrics`
- **レスポンス**: `{ success: true, data: { "1.txt": "...", "124甲.txt": "..." } }` の形式を想定します。
- **キャッシュ**: 取得した `data` はブラウザの `localStorage` に保存されます。

### 2. 書式

各曲の本文は従来と同じく、節ラベルを角括弧で囲みます。

```text
[1]
歌詞の本文
[2]
歌詞の本文
```

### 3. ルビ指定

漢字の後に `(読み)` を記述します。
例: `栄光(えいこう)` → 「栄光」の上に「えいこう」を表示。

## 聖書のページ番号

GitHub Pages側はルートの `bible-pages.json` を読み込み、操作画面・投影画面に旧約／新約のページ番号を表示します。PHPは不要です。

共同入力アプリはアップロード用の `php-server` フォルダに独立しています。PHP 8.1以上の自分のサーバーへフォルダごと配置すると、ページの開始聖句へのチェック、共有保存、日別活動グラフ、書ごとの進捗が使えます。詳細は同フォルダのREADME.mdを参照してください。GitHub Pagesの画面には記入アプリへの案内を設けません。

共同入力画面のヘッダーから書き出した `bible-pages.json` をこのプロジェクトのルートへ置き換え、commit・pushすると表示用データへ反映されます。共同入力サーバーとGitHub Pagesは独立しており、サーバーからGitHubへの自動pushは行いません。

番号は旧約・新約別に印を聖句順に数えて決めます。次の開始位置が登録された時点で、その直前までを同じ番号で補完します。次の印がない最後の区間は未確定です。

動作確認：`node --test tests/*.test.cjs`。共同入力APIは `node --test php-server/tests/bible-pages-api.integration.cjs`（PHPが必要、一時ディレクトリ内で検証）。
